# Übersetzungsaufgaben für os9-dev-skill

Dieses Repo (peacedudes/os9-dev-skill) wird als Wissensbasis für OS-9 aufgebaut.
Ziel: Alle relevanten Texte ins Deutsche übersetzen, Qualitätsprüfung durchführen und eine KI-freundliche Struktur bereitstellen.

Aufgaben:
- README.md: komplette Übersetzung ins Deutsche (Status: offen)
- docs/: alle Markdown-Dateien im docs-Ordner prüfen und übersetzen (Status: offen)
- TUTORIALS/: Schritt-für-Schritt-Anleitungen übersetzen (Status: offen)
- LICENCE, CONTRIBUTING, CODE_OF_CONDUCT: prüfen und ggf. übersetzen (Status: offen)

Vorgehensweise:
1. Dateien in kleine Chargen aufteilen, automatische Vorübersetzung (Machine Translation) mit anschließender menschlicher Revision.
2. Für jede übersetzte Datei einen Pull Request erstellen und Status hier dokumentieren.
3. Metadaten-Datei (translations_manifest.json) zur Nachverfolgung anlegen.
